# Operativa por fases para solicitudes

Este documento define la plantilla y el lugar donde vivirá el proceso en 5 fases que debe seguirse para cada tarea solicitada.

Fases:
1. Preguntas de alcance: invocar al agente `Explore` o al agente de QA para recoger preguntas y aclarar el scope.
2. Revisión de APIs existentes: analizar OpenAPI/Swagger ya disponibles para ver endpoints reutilizables o ampliables.
3. Diseño de la solución: documentar cambios y nuevos endpoints; incluir ejemplos OpenAPI/Swagger y contratos.
4. Validación con usuario: presentar diseño y Swagger para aprobación.
5. Implementación: codificar cambios, tests y despliegue.

Responsables: `desarrollador-apis`, `guardian-antideteccion` y el solicitante.

Ubicación recomendada: `documentacion/procesos/operativa-por-fases.md` (este archivo).
