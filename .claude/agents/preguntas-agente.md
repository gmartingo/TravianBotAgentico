# Agente de preguntas para alcance

Plantilla de interacción para el agente que hará preguntas al solicitante. Debe incluir:
- Objetivo del cambio
- Alcance funcional (endpoints, datos, autenticación)
- Restricciones (seguridad, anti-detección, performance)
- Criterios de aceptación y pruebas deseadas

Guardar prompts y ejemplos aquí para reproducibilidad y auditoría.

Ubicación recomendada: `.claude/agents/preguntas-agente.md`.
